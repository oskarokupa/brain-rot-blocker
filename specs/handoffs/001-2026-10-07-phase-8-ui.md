## Blockers / Notes

**Confirmed design decisions (also in project memory):**
- Child is 9 to 14. Tone must not be babyish.
- UI should look native to YouTube Kids, borrowing styling but not logos.
- Child-facing screens in English and Spanish.
- The parent panel does not need to pass as YouTube Kids. Calmer, denser, settings-page feel.
- Ask with AskUserQuestion before assuming audience, look or language facts.

**How the parent tests:** `npm run build`, reload the extension card on `chrome://extensions`, then refresh the youtubekids.com tab. Skipping the tab refresh leaves a stale content script. Failures are diagnosed from the service worker console (`[brb]` lines), which now print the full API error message.

**Anthropic structured-output schema restrictions, each confirmed by a live 400:**
- `minItems` on arrays accepts only 0 or 1.
- `maxItems` on arrays is not supported at all.
- `minimum` / `maximum` are not supported on `type: integer`. Use `enum` instead.
- Confirmed working: `enum` on integer and string, `minLength`/`maxLength`, plain arrays, nested objects.
- Schema errors surface before the auth check, so a request with a dummy key returns 400 for a bad schema and 401 for a good one. Use that to test schema changes with curl before asking the parent to retest.
- `tests/llmSchema.test.ts` walks both schemas and fails on any of the three.
- Model ids carry no date suffix: `claude-haiku-4-5`.
- Raw `fetch` is used instead of `@anthropic-ai/sdk` on purpose (no extra dependencies, MV3 worker is not a listed SDK runtime).

**Environment quirks:**
- `~/.claude/hooks/damage-control/bash-tool-guard.py` blocks any Bash command whose text contains `.lock` (matches `CONFIG.lock.` and `state.lockEngaged`), `.env`, `secrets.json` or `.claude/`. Write and edit source files with the Write and Edit tools, not Bash heredocs. Keep Bash for build, test, git and grep.
- `~/.codex/config.toml` pins `model = "gpt-6-astra"`, which the installed Codex CLI 0.147.0 cannot use. Every Codex call fails until `codex update` is run or the model is overridden with `--model gpt-5.3-codex-spark`.
- Browser automation tabs on youtube.com sat in buffering and never played, so live playback tests have to come from the parent's own Chrome.

**Loose ends:**
- The quiz screen once stuck on "Getting your challenge ready...". `src/ui/quiz.ts` now retries once and shows a message, but the cause of the failed fetch was never found. It may share a cause with the first-load bug.
- `NOTES.md` still lists the `anthropic-dangerous-direct-browser-access` header as unconfirmed. Live calls succeed with it. Update the note.
- The render watchdog is driven by a 1-minute alarm, so a quiz page whose script never runs at all can take up to a minute to release.
- A worker restart mid-video loses the transcript cache, so that quiz falls to metadata or the bank.
- No keyboard shortcut for the parent PIN, only the long-press. The parent asked about one. Offered, not requested.
- A hook to run a code review before every commit was discussed and deferred by the parent.
- Accepted risks from the plan stand: she can remove the extension, switch site access to "on click", use incognito or another profile. A Chrome policy plist would close these and was declined for v1.
