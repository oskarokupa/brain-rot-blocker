# Curriculum map for the offline question bank

The syllabus the 200 questions are written against, one row per group of sabers from Decret 175/2022 (see `SOURCES.md`). Questions are written in Spanish. Cicle Mitjà (3r and 4t) feeds difficulty 1 and 2, Cicle Superior (5è and 6è) feeds difficulty 3.

"Target" is how many questions the row should hold once the bank reaches 200. "In bank" lists what already covers it, so new questions fill gaps. Each review batch points back to these row ids.

Sabers that need speech, drawing, group work or an image (oral communication, writing production, building figures, charts) are left out, because a text-only quiz cannot test them.
